# Glossary / Glosario (plain language)

Use these when the user asks "¿qué es…?" / "what is…?". Give one or two sentences, and stop there unless they ask for more.

| Term | Español | English |
|---|---|---|
| **Firebase project** / proyecto de Firebase | Un "espacio" en la nube de Google que es solo de tu empresa. Ahí viven los usuarios, los datos compartidos y el sitio web de FreeField. | A private space in Google's cloud that belongs to your company. It holds FreeField's users, shared data and website. |
| **Google Cloud project** | Lo mismo que el proyecto de Firebase, visto desde la consola de Google Cloud (donde TI gestiona permisos y facturación). | The same project, seen from the Google Cloud console, where IT manages permissions and billing. |
| **Project id** / ID del proyecto | El nombre técnico y único del proyecto, p. ej. `acme-field`. Aparece en las direcciones web. | The unique technical name of the project, e.g. `acme-field`. It shows up in web addresses. |
| **Spark / Blaze** | Planes de Firebase. Spark es gratis pero limitado. Blaze es "pago por uso": incluye una cuota gratuita y cobra solo lo que se use por encima. FreeField necesita Blaze. | Firebase plans. Spark is free but limited. Blaze is pay-as-you-go: it includes a free quota and bills only usage above it. FreeField needs Blaze. |
| **Budget alert** / alerta de presupuesto | Un aviso por correo cuando el gasto se acerca a un monto. Avisa, pero no corta el servicio. | An email warning when spending nears an amount. It warns; it doesn't stop the service. |
| **Hosting** | El servicio que publica el sitio web de FreeField en internet, con HTTPS. | The service that puts FreeField's website on the internet, with HTTPS. |
| **Firestore** | La base de datos compartida: proyectos, miembros, incidencias. Se sincroniza en vivo entre usuarios. | The shared database (projects, members, tasks). It syncs live between users. |
| **Storage** | El "disco" en la nube para las fotos de las incidencias y los modelos y planos de los edificios que un admin publica. | Cloud file storage for task photos and model/plan files an admin publishes. |
| **Incidencia** (task / issue) | Un problema o pendiente de obra, ubicado en el modelo o en el plano, con tipo, estado, responsable y fotos. En la interfaz en inglés se llama "task". | A site issue or to-do pinned to the model or a plan, with type, status, assignee and photos. The Spanish UI calls it "incidencia". |
| **Plano** (PDF plan) | Un dibujo en PDF (planta, corte…) cargado en FreeField y calibrado con el modelo. | A PDF drawing (floor plan, section…) loaded into FreeField and calibrated against the model. |
| **Publicar un edificio** (publish a building) | Que un admin suba el modelo convertido y los planos de un edificio al proyecto de la empresa, para que todo el equipo los vea. | An admin uploads a building's converted model and plans to the company project so the whole team sees them. |
| **Cloud Functions** | Pequeños programas que corren en el servidor para acciones sensibles: invitar, cambiar roles, crear el primer admin. | Small server-side programs for sensitive actions: inviting, changing roles, creating the first admin. |
| **Authentication / email link** | Inicio de sesión sin contraseña: escribes tu correo, recibes un enlace y al hacer clic entras. | Passwordless sign-in: you type your email, get a link, click it and you're in. |
| **Authorized domains** / dominios autorizados | La lista de direcciones web desde las que Firebase acepta inicios de sesión. Si falta tu dominio, el enlace no funciona. | The web addresses Firebase accepts sign-ins from. If your domain is missing, the link fails. |
| **Security rules** / reglas de seguridad | Reglas que el servidor revisa en cada lectura o escritura: quién puede ver o cambiar qué. Están en el código de FreeField. | Rules the server checks on every read or write: who can see or change what. They're in FreeField's code. |
| **Region** / región | El lugar físico (centro de datos) donde se guardan los datos, p. ej. `southamerica-west1` (Santiago). Para Firestore y Storage se elige una vez y no se puede cambiar. Las funciones de FreeField corren hoy en `us-central1` (EE. UU.). | The physical place (data centre) where data is stored, e.g. `southamerica-west1` (Santiago). For Firestore and Storage you choose it once; it can't be changed. FreeField's functions run in `us-central1` (USA) today. |
| **Deploy** / desplegar | Publicar una versión nueva: reglas, funciones y sitio web, en ese orden. | Publish a new version: rules, functions and website, in that order. |
| **Build** / compilar | Convertir el código en los archivos que entiende el navegador (carpeta `apps/settings/dist`). | Turn the code into the files a browser runs (the `apps/settings/dist` folder). |
| **`.env` file** / archivo `.env` | Un archivo de texto con la configuración (qué proyecto usar, si el demo está activo). No se sube a git. | A text file with settings (which project to use, whether demo mode is on). It's kept out of git. |
| **Demo mode** / modo demo | FreeField sin servidor ni inicio de sesión; todo queda en tu navegador. Ideal para probar, nunca para la empresa. | FreeField with no server and no sign-in; everything stays in your browser. Good for trying it, never for company use. |
| **Emulator** / emulador | Una copia local de Firebase para probar en tu computador, sin tocar la nube. Necesita Java 21. Solo para desarrolladores. | A local copy of Firebase for testing on your computer without touching the cloud. Needs Java 21; for developers. |
| **CLI / terminal** | La ventana donde se escriben comandos. Claude los escribe por ti y te explica cada uno. | The window where commands are typed. Claude types them and explains each one. |
| **firebase login** | Inicio de sesión en el navegador que autoriza a este computador a publicar en tu proyecto. Claude nunca ve tu contraseña. | A browser sign-in that lets this computer publish to your project. Claude never sees your password. |
| **Alias (staging / prod)** | Apodos para tus proyectos: "staging" para probar y "prod" para la versión real que usa el equipo. | Nicknames for your projects: "staging" for testing, "prod" for the real one the team uses. |
| **Rollback** / revertir | Volver a la versión anterior del sitio con un clic, desde la consola de Hosting. | Go back to the previous website version with one click in the Hosting console. |
| **Backup** / respaldo | Copia periódica de la base de datos (Firestore) para recuperarla si algo sale mal. | A periodic copy of the database (Firestore) to restore if something goes wrong. |
| **IAM role** / rol IAM | El permiso que TI te da en el proyecto (p. ej. Propietario, Firebase Admin). "Editor" no alcanza para poner FreeField en marcha. | The permission IT grants you on the project (e.g. Owner, Firebase Admin). "Editor" isn't enough to set FreeField up. |
| **Billing account** / cuenta de facturación | La cuenta de Google Cloud con el medio de pago, normalmente de finanzas. El proyecto se "vincula" a ella para usar Blaze. | The Google Cloud account holding the payment method, usually owned by finance. The project is "linked" to it to use Blaze. |
| **Organization** / organización de Google Cloud | El "contenedor" de la empresa en Google Cloud, donde TI aplica políticas a todos los proyectos. | The company's top-level container in Google Cloud, where IT applies policies to all projects. |
| **Staging / producción** | Staging es una copia para probar cambios; producción es la que usa el equipo. Un piloto puede funcionar solo con producción, con más cuidado. | Staging is a copy for testing changes; production is what the team uses. A pilot can run on production only, with extra care. |
| **DNS (A / TXT records)** / registros DNS | Las entradas que conectan tu dominio (p. ej. `terreno.empresa.cl`) con Firebase Hosting. Las crea TI. | Entries that point your domain (e.g. `field.company.com`) to Firebase Hosting. IT creates them. |
| **Upstream / fork** | "Upstream" es el repositorio público original de FreeField; tu "fork" es la copia de tu empresa, que recibe actualizaciones desde upstream. | "Upstream" is the original public FreeField repository; your "fork" is your company's copy, which pulls updates from upstream. |
| **SLA** | Compromiso formal de disponibilidad y soporte. FreeField (código abierto) no tiene SLA. | A formal availability and support commitment. FreeField (open source) has none. |

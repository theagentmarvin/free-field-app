# Vendored BCF XML schemas

Verbatim, unmodified copies of the official buildingSMART BCF-XML schemas, used only by the
export tests to validate generated files.

- `2.1/` from https://raw.githubusercontent.com/buildingSMART/BCF-XML/release_2_1/Schemas/
  (`markup.xsd`, `visinfo.xsd`, `version.xsd`, `project.xsd`)
- `3.0/` from https://raw.githubusercontent.com/buildingSMART/BCF-XML/release_3_0/Schemas/
  (`markup.xsd`, `visinfo.xsd`, `version.xsd`, `project.xsd`, `extensions.xsd`, `documents.xsd`,
  `shared-types.xsd`)

Downloaded: 2026-11-22.
